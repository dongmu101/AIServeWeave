# Triage Labels

工程技能使用以下角色名；本地 Markdown 任务的 `Status:` 使用对应字符串。

| 技能角色 | 本仓库状态字符串 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待提交者补充信息 |
| ready-for-agent | ready-for-agent | 规格完整，可交由代理执行 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不予实施 |

技能提及某种 triage 角色时，使用此表对应的状态字符串。
需要调整命名时，直接修改本表。
